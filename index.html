TOEFL 학습실

2026년 개편된 TOEFL iBT 구성(리딩 3형식·리스닝 4형식·라이팅 3형식·스피킹 2형식)에 맞춰 직접 등록한 문제로 연습해요.

설정

API 키 설정 (AI 첨삭용)

단어 자동완성 · AI 첨삭을 쓰려면 본인 Anthropic API 키가 필요해요. 공용 키는 없어요. console.anthropic.com에서 발급받을 수 있고, 쓴 만큼만 과금돼요. 단어 자동완성은 Haiku 4.5(1회 1원 미만), 라이팅 첨삭은 판단이 필요해서 Sonnet 5를 써요(1회 10원 안팎).

키는 이 브라우저의 localStorage에만 저장되고 서버로 전송되지 않아요. 다만 이 컴퓨터/브라우저에 접근하는 다른 사람도 볼 수 있으니 공용 기기에서는 주의해주세요.

화면 테마

시험 화면은 실전과 같게 흰 배경이라 밤에 눈이 부실 수 있어요. 색 대비는 그대로 두고 전체 밝기만 낮춰요.

저장 공간

브라우저가 이 사이트에 허용하는 저장 공간은 약 5 MB예요. 대부분 첨부한 사진이 차지해요.

계정 · 기기 간 동기화

로그인해서 노트북·휴대폰이 같은 데이터를 쓰려면 무료 Supabase 프로젝트가 하나 필요해요. supabase.com에서 프로젝트를 만들고, Project Settings → API에서 아래 두 값을 복사해오세요.

  2. 왼쪽 메뉴 SQL Editor → 아래 SQL 붙여넣고 Run
  3. Project Settings → API 에서 Project URL과 anon public 키를 복사해 아래에 입력
